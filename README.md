# 📊 Organizador de Declaração de Imposto de Renda

Projeto desenvolvido em **Microsoft Excel** para facilitar a organização e o controle de informações utilizadas na preparação da Declaração de Imposto de Renda.

A ferramenta foi construída com foco em **organização de dados, praticidade e navegação intuitiva**, utilizando validações de dados, funções interativas e uma estrutura visual organizada.

## 🎯 Objetivo

Criar uma solução prática e profissional para centralizar informações fiscais em um único lugar, facilitando o preenchimento, a consulta e o acompanhamento dos dados.

O projeto também foi desenvolvido como uma aplicação prática dos conhecimentos de **Excel, organização de dados e automação de processos**, podendo ser utilizado como projeto de portfólio.

## 🗂️ Estrutura do projeto

O organizador é dividido em **3 abas principais**, conectadas por uma navegação simples e intuitiva.

### 👤 1. Titular

Área destinada ao preenchimento dos principais dados do titular da declaração, como:

- Nome
- CPF
- Data de nascimento
- Título de eleitor
- Cônjuge
- Endereço
- CEP
- Telefone e celular
- E-mail
- Informações sobre a declaração anterior
- Dependentes e residência no exterior

![Aba Titular](imagens/aba-titular.png)

---

### 🏦 2. Informes

Área destinada à organização dos **informes de rendimentos bancários**.

É possível cadastrar diferentes instituições financeiras, informar o valor atual de cada conta e relacionar os respectivos documentos.

A aba também apresenta o **valor total**, facilitando a visualização dos valores cadastrados.

![Aba Informes](imagens/aba-informes.png)

---

### 📝 3. Notas

Área destinada ao registro das **entradas de valores mês a mês**, permitindo organizar informações provenientes de holerites e outras receitas.

A tabela conta com campos para:

- Data
- Categoria
- Valor

![Aba Notas](imagens/aba-notas.png)

O projeto utiliza diferentes recursos do Excel para tornar a experiência mais prática e interativa:

- ✅ Validação de dados

- ✅ Cálculos automáticos
- ✅ Navegação entre abas
- ✅ Campos estruturados para preenchimento

## 💡 Principais aprendizados

Este projeto permitiu colocar em prática conhecimentos de **Excel e organização de dados**, além de desenvolver uma solução pensando na experiência de quem irá utilizá-la.

Entre os principais aprendizados estão:

- Estruturação e organização de informações;
- Utilização de validações de dados;
- Criação de campos interativos;
- Aplicação de funções e fórmulas;
- Desenvolvimento de uma navegação mais intuitiva;
- Criação de uma interface visual funcional;
- Transformação de uma necessidade prática em uma solução utilizando Excel.

## 🛠️ Ferramenta

**Microsoft Excel**

## 📌 Sobre o projeto

Este projeto foi desenvolvido para fins de **aprendizado e portfólio**, demonstrando a aplicação prática de recursos do Excel na criação de uma ferramenta de organização de dados fiscais.

A proposta é oferecer uma solução simples, organizada e funcional para quem busca centralizar suas informações e facilitar a preparação dos dados para a Declaração de Imposto de Renda.

> **Observação:** Este projeto tem finalidade organizacional e educacional e não substitui orientação de um profissional contábil ou tributário.
